# DepositJudge Frontend

This directory contains the user interface for DepositJudge, built with React, TypeScript, Vite, and vanilla CSS featuring modern glassmorphic aesthetics. It communicates with the decentralized GenLayer Studio Network (studionet) using `genlayer-js`.

## Configuration
The default contract address is injected via Vite environment variables:
`VITE_CONTRACT_ADDRESS=0x3316cF283e8E9709c5DE8eA4dE0B4D3f4bfc46Db`
`VITE_GENLAYER_CONTRACT_ADDRESS=0x3316cF283e8E9709c5DE8eA4dE0B4D3f4bfc46Db`

## Scripts
- `npm run dev`: Start Vite development server
- `npm run build`: Build optimized bundle for production
- `npm run preview`: Preview built production bundle locally
